# Parametric Glitches for Bilby

This package implements an interface to allow inference with parametric glitches in `bilby` and `bilby_pipe`, as well as implementing a number of these models.
Currently it is oriented towards use with scattering (slow and fast) glitches. 
These documentation pages are still under development, and refactoring of the package for increased accessibility outside of bilby contexts is also under way.
