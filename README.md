## Contributing to this Software

### Development environment
This repository uses `pre-commit` running `ruff` to maintain readability.
To get required software, do `pip install -r requirements.txt`, then run `pre-commit install`in this repository. 
If the repository is currently failing pre-commit checks in the CI pipeline, do `pre-commit run --all` and `add/commit` the results.
